## E-Commerce Funnel Analysis Dashboard

Interactive business intelligence dashboard built using Power BI and SQL.

## Project Overview

This project analyzes e-commerce performance using funnel analytics and KPI tracking.

## Key Metrics

* ₹10.99M Revenue
* 1K+ Orders
* 786 Customers
* Conversion Funnel Analysis

## Dashboard Insights

* Revenue trends over time
* Top cities by revenue
* Category contribution
* Funnel drop-off stages
* Interactive slicers
